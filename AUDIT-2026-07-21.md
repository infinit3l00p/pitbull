## Executive Summary

PITBULL is a sophisticated autonomous digital exploration platform with 7 phases of development completed. The system is **largely functional** with 48/50 API endpoints responding correctly. Core exploration missions work end-to-end (DNS recon → subdomain enumeration → certificate transparency → web crawling → deep web probing → vulnerability analysis → LLM reasoning → memory consolidation → personality evolution). The frontend builds successfully and serves a 13-page dashboard. 

There are a few known issues: external API timeouts (Wayback, GitHub code search), missing API keys (Shodan, GitHub token), a Neo4j date parsing bug in pattern discovery, and the bundle size is large. The system was renamed from ABYSS to PITBULL across all 79 source files (663 replacements).

## ❌ NOT WORKING (2 failures)

### 1. Wayback Machine API — TIMEOUT
- **Endpoint:** `GET /api/v1/wayback/snapshots/{domain}`
- **Error:** 503 Service Unavailable from web.archive.org
- **Root Cause:** The Wayback Machine CDX API is returning 503 errors. This is an external service issue, not a PITBULL bug. The 15s timeout correctly prevents hanging.
- **Impact:** Historical snapshot analysis unavailable
- **Fix:** Retry later or add a fallback to archive.org's Save Page Now API

### 2. GitHub Code Search — TIMEOUT
- **Endpoint:** `GET /api/v1/github/search/code?query=...`
- **Error:** Request times out (GitHub API requires authentication for code search)
- **Root Cause:** GitHub Code Search API requires authentication. No `PITBULL_GITHUB_TOKEN` is set. Without a token, GitHub returns 401 which may not be handled correctly.
- **Impact:** Leaked secret detection via GitHub code search doesn't work
- **Fix:** Set `PITBULL_GITHUB_TOKEN` env var with a GitHub personal access token

## 🔧 IMPROVEMENTS RECOMMENDED

### High Priority

1. **Fix Neo4j Date Parsing Bug in patterns.py**
   - Pattern discovery fails with: `Text cannot be parsed to a Date "2026-05-31T21:39:00"`
   - Line 218: `avg(duration.between(date(c.not_before), date()).months)`
   - Certificate `not_before` field stored as string, not date
   - **Fix:** Convert to date in Cypher: `date(replace(substring(c.not_before, 0, 10), '-', '-'))`

2. **Frontend Bundle Size — 1MB JavaScript**
   - Vite warning: chunk > 500KB after minification
   - Single 1MB JS bundle loads entirely on first page visit
   - **Fix:** Use dynamic imports for code-splitting per page:
     ```ts
     const ExploitPage = lazy(() => import('./pages/Exploit'));
     const SentinelPage = lazy(() => import('./pages/Sentinel'));
     ```
   - Would reduce initial load by ~60%

3. **Add Request Rate Limiting**
   - API key is the only auth — no rate limiting
   - A compromised key could spam external APIs
   - **Fix:** Add `slowapi` middleware:
     ```python
     from slowapi import Limiter
     limiter = Limiter(key_func=get_remote_address)
     app.state.limiter = limiter
     ```

4. **Git Repository — Uncommitted Files**
   - Many untracked files (new API modules, collectors, etc.)
   - Git working tree has uncommitted changes
   - **Fix:** Stage and commit all changes

5. **Stale Personality State File Location**
   - Personality state stored at `/run/pitbull/personality.json` (was `/run/abyss/`)
   - `/run` is tmpfs — resets on reboot
   - State survives within session but resets on restart
   - **Fix:** Move to persistent location like `~/.local/share/pitbull/personality.json`

### Medium Priority

6. **API Key Hardcoded in config.py**
   - Default key `pitbull-explorer-dev-key-2026` in source code
   - Fine for local dev, but should use env var exclusively
   - **Fix:** Remove default, require env var

7. **Frontend `package-lock.json` Still Has Old Name References**
   - Lock file may reference `abyss-frontend` internally
   - **Fix:** Delete and regenerate: `rm package-lock.json && npm install`

8. **Crawler User Agent Stale**
   - Config: `PITBULL/0.1 (+https://github.com/abyss)` → now `pitbull/0.1 (+https://github.com/pitbull)`
   - Version says 0.1 but app is 0.7.0
   - **Fix:** Update user agent string and version

9. **README Still References Old Phase Status**
   - Says "Phase 2 (Planned)" but Phase 7 is complete
   - **Fix:** Update README to reflect current state

10. **No Tests / CI**
    - No unit tests, integration tests, or CI pipeline
    - For a portfolio piece, tests would strengthen the submission
    - **Fix:** Add pytest tests for core modules, GitHub Actions CI

### Low Priority

11. **Double-Prefix in OpenAPI Paths**
    - Some routers have prefix + route prefix duplication
    - Cosmetic only — doesn't affect functionality

12. **Backend Bound to 127.0.0.1**
    - Good for security, but if remote access needed, requires reverse proxy
    - **Note:** Current binding is correct for local use

13. **No WebSocket Support**
    - Real-time updates use SSE (unidirectional)
    - WebSocket would enable bidirectional communication for chat/interactive features
    - **Fix:** Consider WebSocket for Chat page

14. **Memory Graph Visualization Could Be Better**
    - Cytoscape.js works but initial load of 500 nodes can be slow
    - **Fix:** Add node filtering, pagination, or lazy loading

15. **Error Handling Could Be More Granular**
    - Many endpoints return generic error dicts
    - Could use proper HTTP status codes (429 for rate limits, 502 for upstream failures)
